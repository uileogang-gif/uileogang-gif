## 重点开源项目

### `solstice-dsp`
> *基于 Rust 开发的零堆内存分配、纯头文件级空间音频卷积引擎。*
- **核心架构**: 集成 SIMD 分块 FFT 卷积算法的 B-format 高保真立体混响解码器。
- **延迟保障**: 在 96kHz / 64 采样点缓冲区设置下，无需任何动态堆分配即可达成低于 1.2ms 的处理耗时。
- **运行平台**: 原生桌面端（Linux/macOS/Windows）以及面向现代 Web 交互式合成器的 WebAssembly 编译目标。

### `pulsefield`
> *专为户外偏远生态监听站设计的超低功耗声学遥测守护进程。*
- **硬件集成**: 运行定制 STM32 固件，支持 LTE-M / LoRaWAN 窄带传输与 SD 卡环形缓冲容灾回退。
- **压缩方案**: 针对弱电网、间歇性太阳能爆发传输优化的自适应 FLAC 帧打包机制。
- **环境韧性**: 硬件级看门狗定时器与容错状态恢复程序，足以抵御北欧严酷漫长的极地极寒环境。

### `decibel-tui`
> *严格遵循 ITU-R BS.1770-4 与 EBU R128 广播标准的终端级音频响度分析器。*
- **用户交互**: 基于 ratatui 构建的全键盘驱动终端 UI，支持高刷新率 True-Peak 与瞬态/全局 LUFS 积分记录。
- **驱动直通**: 绕过桌面环境的多层混音器，直连 ALSA 与 CoreAudio 底层音频驱动。

## 工程哲学

1. **确定性关键路径**: 在实时音频回调线程中，严禁进行堆内存分配、互斥锁竞争或非确定性的文件与网络 I/O。
2. **第一性原理**: 在引入任何高层抽象前，务必透彻理解 CPU 缓存层次、指令周期延迟与硅片晶体管物理极限。
3. **敬畏物理寿命**: 编写精简无冗余依赖的模块化代码，确保十年后它依然能在低功耗微芯片上无须维护地编译并平稳运行。
